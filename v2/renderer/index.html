Cookie và phiên đăng nhập được lưu riêng cho từng profile.

Đang tải profiles…Chromium · Local profiles

Profile được lưu trên máy này. Bạn có thể đóng Chromium và mở lại để tiếp tục phiên làm việc.

Tạo profile mới

Hỗ trợ Mail|Password|RecoveryMail|2FA|SecurityCode|Passkey hoặc khối nhiều dòng: Email:, Password:, Recovery:, 2FA key:, Security code:, Passkey:. Dòng email có thể bỏ nhãn Email:. Mỗi email bắt đầu một profile mới; RecoveryMail, 2FA, Security Code, Passkey có thể để trống (hỗ trợ cả định dạng không có email khôi phục hoặc dạng Mail||Password|2FA...).

Fingerprint lấy từ Template, mỗi profile có seed riêng. Dữ liệu tài khoản được mã hóa và lưu trên máy; chưa tự đăng nhập Gmail.
Template fingerprint

GPU Vendor/Renderer được chọn theo seed hoặc dùng GPU thật; bản 148 không hỗ trợ nhập tên GPU tùy ý. Múi giờ theo IP, Google services và proxy có mật khẩu của GoLogin chưa được hỗ trợ.
Cài đặt Firebase Sync

Cấu hình ứng dụng. Các thay đổi được lưu trên máy và đồng bộ lên Firebase.

Server GCP (Google Ads API) OAuth & Developer Token từ Google Cloud Platform. Server "Đang dùng" được dùng để tạo link đăng nhập Ads và quét MCC.

Chưa có server GCP nào. Bấm "Thêm server GCP" để thêm.

Pool worker (Google Ads API) Mọi lệnh gọi Google Ads API chạy qua pool này: tự dò trần concurrency, dính quota thì giảm một nửa và back off. Nút lưu riêng, áp ngay và đồng bộ Firebase.

Các thông tin khóa bí mật (Client Secret, Developer Token, Refresh Token) được mã hóa an toàn bằng safeStorage trước khi lưu vào máy.
Tạo link đăng nhập Ads (OAuth2)

Tạo đường dẫn đăng nhập và cấp quyền Google Ads API (scope adwords). Mở link này trong trình duyệt của profile để đăng nhập và lấy mã cấp quyền.

Đổi mã Code lấy Refresh Token tự động Sau khi bấm "Cho phép" ở trình duyệt, trang sẽ chuyển hướng về http://127.0.0.1/?code=.... Dán URL đó (hoặc mã code) vào ô dưới đây để tự động lấy Refresh Token và lưu vào server GCP đang dùng & Firebase.

Xác minh tài khoản Google Ads

Nhập ID tài khoản quản lý (MCC) để quét danh sách các tài khoản con cần xác minh danh tính nhà quảng cáo (Advertiser Verification).

Hệ thống sẽ dùng server GCP đang dùng (trong Cài đặt) để tự động truy vấn danh sách tài khoản con và kiểm tra trạng thái xác minh.
